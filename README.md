# Diwali Sales Analysis – Python EDA

Exploratory Data Analysis on Diwali sales data to help a business 
understand their customers and boost sales for future festive seasons.

## Objective
Identify potential customers across different states, occupations, 
gender, and age groups to improve targeting and sales strategy.

## Dataset
- 11,000+ records of customer purchase data
- Features: Gender, Age Group, State, Marital Status, Occupation, 
  Product Category, Orders, Amount

## Key Insights
- 👩 Most buyers are **females** aged **26–35 years**
- 📍 Top states by orders & revenue: **Uttar Pradesh, Maharashtra, Karnataka**
- 💍 **Married women** have the highest purchasing power
- 💼 Buyers mostly work in **IT, Healthcare, and Aviation**
- 🛍️ Top selling categories: **Food, Clothing, Electronics**

## Tools & Libraries
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## How to Run
1. Clone the repo
2. Install dependencies:
   pip install pandas numpy matplotlib seaborn
3. Open the notebook:
   jupyter notebook Diwali_Sales_Analysis.ipynb
